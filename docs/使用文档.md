## 1. 快速开始

### 30 秒上手示例

```python
from neo_legend.models import RenderRequest
from neo_legend.registry import build_default_registry

# 1️⃣ 创建注册表（加载所有图表类型）
registry = build_default_registry()

# 2️⃣ 创建渲染请求
request = RenderRequest(
    legend_type="radar_chart",     # 图表类型
    style="neon_glow",            # 样式风格
    width=1200,                   # 图片宽度 (px)
    height=1400,                  # 图片高度 (px)
    title="球员能力雷达图",        # 自定义标题
    subtitle="2025-26 赛季数据"     # 自定义副标题
)

# 3️⃣ 渲染并获取图片
result = registry.render(request)

# 4️⃣ 保存到文件
with open("output.png", "wb") as f:
    f.write(result.content)        # result.content 是 PNG/GIF 字节数据

print(f"✅ 生成成功！格式: {result.media_type}, 大小: {len(result.content):,} 字节")
```

## 3. API 接口参考

### 基础信息

- **Base URL**: `http://localhost:8000`
- **Content-Type**: `application/json`
- **认证方式**: 无需认证（开发模式）

### 3.1 健康检查

```http
GET /health
```

**响应**:
```json
{
  "status": "ok"
}
```

---

### 3.2 获取所有图表类型

```http
GET /legend-types
```

**响应** (200 OK):
```json

  {

      {"name": "hex", "description": "Hexagonal binning heatmap."},
      {"name": "zone", "description": "Zone-based efficiency labels."}
    ],
    "media_type": "image/png"
  },
  // ... 其他 13 种类型
]
```

---

### 3.3 渲染图片（GET 方式）

```http
GET /render?legend_type={type}&style={style}&width={w}&height={h}&title={t}
```

**查询参数**:

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `legend_type` | string | ✅ 是 | - | 图表类型标识符 |
| `style` | string | 否 | `"default"` | 样式变体名称 |
| `width` | integer | 否 | `1179` | 输出宽度 (640-2400) |
| `height` | integer | 否 | 自动 | 输出高度 (640-3200) |
| `title` | string | 否 | 无 | 自定义标题 |
| `subtitle` | string | 否 | 无 | 自定义副标题 |

**响应头**:
```
Content-Type: image/png (或 image/gif)
Content-Disposition: inline; filename="court_shot-terrain.png"
X-Legend-Type: court_shot
X-Legend-Style: terrain
```

**响应体**: 二进制图片数据

**示例请求**:
```bash
curl "http://localhost:8000/render?legend_type=radar_chart&style=neon_glow&width=1200&height=1400" \
  --output radar_chart.png
```

## 4. Python SDK 使用

### 4.1 基础用法

```python
from neo_legend.models import RenderRequest
from neo_legend.registry import build_default_registry

# 初始化
registry = build_default_registry()

# 最简调用（使用默认参数）
request = RenderRequest(legend_type="court_shot")
result = registry.render(request)

# 保存图片
with open("chart.png", "wb") as f:
    f.write(result.content)

# 获取元数据
print(f"类型: {result.legend_type}")
print(f"样式: {result.style}")
print(f"格式: {result.media_type}")      # image/png 或 image/gif
print(f"扩展名: {result.file_extension}")   # png 或 gif
```

### 4.2 查询可用类型和样式

```python
from neo_legend.registry import build_default_registry

registry = build_default_registry()

# 获取所有已注册的图表类型
types = registry.list_types()
for t in types:
    print(f"\n📊 [{t.legend_type}] {t.display_name}")
    print(f"   默认样式: {t.default_style}")
    print(f"   可用样式:")
    for s in t.styles:
        print(f"      • {s.name}: {s.description}")
```

**输出示例**:
```
📊 [radar_chart] Luxury Radar Chart
   默认样式: neon_glow
   可用样式:
      • neon_glow: 霓虹发光效果
      • crystal_metal: 晶体金属质感
      • gradient_rainbow: 彩虹渐变
```

### 4.4 批量生成示例

```python
from neo_legend.registry import build_default_registry
from neo_legend.models import RenderRequest
import os

registry = build_default_registry()
output_dir = "batch_output"
os.makedirs(output_dir, exist_ok=True)

# 遍历所有类型和样式
for type_meta in registry.list_types():
    for style_info in type_meta.styles:
        request = RenderRequest(
            legend_type=type_meta.legend_type,
            style=style_info.name,
            width=900,
            height=900
        )
        result = registry.render(request)
        
        filename = f"{type_meta.legend_type}__{style_info.name}.png"
        with open(os.path.join(output_dir, filename), "wb") as f:
            f.write(result.content)
        
        print(f"[OK] {filename}")

print(f"\n✅ 完成！共生成图片于: {os.path.abspath(output_dir)}")
```

## 5. 14 种图例类型详解

### 5.1 🏀 Court Shot（球场投射图）

**用途**: 展示篮球运动员在球场上的投篮热力分布，类似 Kirk Goldsberry 风格。

| 属性 | 值 |
|------|-----|
| **类型标识** | `court_shot` |
| **显示名称** | Court Shooting Terrain |
| **默认尺寸** | 1179 × 1454 px |
| **输出格式** | PNG |

#### 可用样式

| 样式名 | 描述 | 视觉特色 |
|--------|------|---------|
| `terrain` | Kirk Goldsberry 经典地形 | 红色渐变热力 + 半透明网格 + 区域效率标注 |
| `hex` | 六边形网格热力 | 六边形 bin 聚类 + 色彩映射 |
| `zone` | 区域效率标注 | 分区着色 + 百分比标签 |

#### 数据参数

```python
data = {
    "shot_count": 500,    # 投篮采样数量 (默认 500)
    "seed": 42           # 随机种子 (用于复现结果)
}
```

#### 适用场景
- 球员投篮热点分析
- 季度/赛季对比
- 战术布局优化

---

### 5.2 ⚖️ Dual Court Shot（双球场对比图）

**用途**: 上下或左右并列展示两个时间段的球场数据，直观对比差异。

| 属性 | 值 |
|------|-----|
| **类型标识** | `dual_court_shot` |
| **显示名称** | Dual Court Shooting Comparison |
| **默认尺寸** | 1179 × 1800 px |

#### 可用样式

| 样式名 | 描述 |
|--------|------|
| `year_over_year` | 年度对比（上下双面板） |
| `split_hex` | 分裂六边形对比 |

#### 数据参数

```python
data = {
    "panels": [
        {
            "season": "2024-25",
            "attempts": "79 GAMES / 808 ATTEMPTS",
            "seed": 12,                          # 随机种子
            "metrics": {
                "FG%": "47.6%",                  # 投篮命中率
                "3P%": "33.2%",                   # 三分命中率
                "eFG%": "53.7%"                  # 有效命中率
            }
        },
        {
            "season": "2025-26",
            "attempts": "71 GAMES / 774 ATTEMPTS",
            "seed": 44,                            # ≠ 12 会触发 "MOST IMPROVED" 徽章
            "metrics": {...}
        }
    ]
}
```

#### 特色功能
- ✅ 自动计算 FG%/3P%/eFG% 统计面板
- ✅ 当 seed 不同时显示绿色 "MOST IMPROVED" 徽章
- ✅ 显示各区域效率百分比标注

---

### 5.3 🎬 Animated Court Shot（动态球场图）

**用途**: 生成 GIF 动画形式的球场投射图，展示动态效果。

| 属性 | 值 |
|------|-----|
| **类型标识** | `court_shot_animation` |
| **显示名称** | Animated Court Shooting |
| **默认尺寸** | 700 × 700 px |
| **输出格式** | **GIF** |

#### 可用样式

| 样式名 | 描述 | 动画特点 |
|--------|------|---------|
| `pulse` | 脉冲动画 | 投篮点闪烁脉冲效果 |
| `sweep` | 扫描动画 | 逐帧扫描展示轨迹 |

#### 数据参数

```python
data = {
    "frame_count": 20   # 动画帧数 (默认 15)
}
```

---

### 5.4 📈 Coordinate（坐标散点图）

**用途**: 二维坐标散点图，支持气泡大小变化，适合展示多维度数据关系。

| 属性 | 值 |
|------|-----|
| **类型标识** | `coordinate` |
| **显示名称** | Coordinate Scatter Plot |
| **默认尺寸** | 1179 × 909 px |

#### 可用样式

| 样式名 | 描述 | 视觉风格 |
|--------|------|---------|
| `dark_bubble` | 暗色气泡散点 | 深色背景 + 彩色气泡 + 标签 |
| `gold_scorers` | 金色得分手 | 金色调配色 + 散点标签 |

#### 数据参数

```python
data = {
    "points": [
        {"name": "球员A", "x": 22.0, "y": 65.3, "size": 400, "color": "#FDB927"},
        {"name": "球员B", "x": 28.5, "y": 58.2, "size": 350, "color": "#06AAF4"},
        # ...
    ]
}
```

**字段说明**:
- `name`: 数据点标签文本
- `x`: X 轴数值
- `y`: Y 轴数值
- `size`: 气泡大小（影响圆的直径）
- `color`: 气泡颜色（十六进制）

---

### 5.5 ➕➖ Plus-Minus Coordinate（正负坐标四象限图）

**用途**: 四象限划分图，常用于展示攻防效率、正负贡献等双向指标。

| 属性 | 值 |
|------|-----|
| **类型标识** | `plus_minus_coordinate` |
| **显示名称** | Plus-Minus Quadrant Chart |
| **默认尺寸** | 909 × 909 px |

#### 可用样式

| 样式名 | 描述 | 背景 |
|--------|------|------|
| `paper_quadrant` | 纸张纹理四象限 | 米色纹理背景 |
| `clean_quadrant` | 干净四象限 | 纯白/浅灰背景 |

#### 数据参数

```python
data = {
    "points": [
        {"label": "球队A", "x": 5.0, "y": 5.0, "color": "#ff0000"},
        {"label": "球队B", "x": -5.0, "y": -5.0, "color": "#0000ff"},
```

## 8. 常见问题 FAQ

### Q1: 如何更改输出图片的质量/DPI？

**A**: 当前系统固定使用 DPI=150。如需调整，可以修改 `_plotting.py` 中的 `save_png()` 函数：

```python
fig.savefig(buffer, format=format, dpi=300, ...)  # 提高到 300 DPI
```

---

### Q2: 生成的图片太大怎么办？

**A**: 几种优化方案：

1. **减小尺寸**: `width=800, height=600`
2. **简化数据**: 减少数据点数量
3. **选择轻量样式**: 如 `clean_quadrant` 比 `paper_quadrant` 更简洁
4. **压缩输出**: 使用 Pillow 重新压缩：

```python
from PIL import Image
import io
img = Image.open(io.BytesIO(result.content))
img.save("compressed.png", optimize=True, quality=85)
```

---

### Q3: 中文字体显示为方框（□□）怎么办？

**A**: 这是字体缺失问题。解决方案：

```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'DejaVu Sans']
```

或在系统中安装中文字体包。

### Q5: 支持导出为 SVG/PDF 格式吗？

**A**: 当前版本仅支持 **PNG** 和 **GIF** 格式。如需其他格式：

```python
from PIL import Image
import io

# PNG 转 PDF（多页）
img = Image.open(io.BytesIO(result.content))
img.convert("RGB").save("output.pdf", "PDF", resolution=150)

# PNG 转 SVG（需要 cairosvg 库）
# pip install cairosvg
import cairosvg
cairosvg.png2svg(fileobj=io.BytesIO(result.content), write_to="output.svg")
```

| 简单图表（table, coordinate） | 50-100ms | ~20MB |
| 中等复杂（bar, rose, radar） | 100-300ms | ~50MB |
| 复杂图表（sankey, combo） | 300-800ms | ~80MB |
| 动画 GIF（animated_court_shot） | 1-3s | ~150MB |

**建议**: 
- 生产环境使用异步 workers（gunicorn/uvicorn workers）
- 添加 Redis 缓存常用图表
- 图片生成后存储到 OSS/S3，避免重复生成
