## 1. 快速开始

### 30 秒上手示例

```python
from neo_legend.models import RenderRequest
from neo_legend.registry import build_default_registry

registry = build_default_registry()

request = RenderRequest(
    legend_type="radar_chart",
    style="neon_glow",
    width=1200,
    height=1400,
    title="球员能力雷达图",
    subtitle="2025-26 赛季数据"
)

result = registry.render(request)

with open("output.png", "wb") as f:
    f.write(result.content)

print(f"生成成功! 格式: {result.media_type}, 大小: {len(result.content):,} 字节")
```

### 带奢华主题的渲染

```python
request = RenderRequest(
    legend_type="bar_chart",
    style="glass_3d",
    data={
        "luxury_theme": "obsidian_gold",
        "luxury_theme_intensity": 1.5,
        "labels": ["Q1", "Q2", "Q3", "Q4"],
        "values": [85, 72, 90, 68]
    }
)
result = registry.render(request)
```

### 3.4 GET /render — 渲染图片（查询参数方式）

```http
GET /render?legend_type={type}&style={style}&width={w}&height={h}&title={t}&luxury_theme={theme}&luxury_theme_seed={seed}&luxury_theme_intensity={intensity}
```

#### 查询参数

| 参数 | 类型 | 必填 | 默认值 | 约束 | 说明 |
|------|------|------|--------|------|------|
| `legend_type` | string | ✅ 是 | - | min_length=1 | 图表类型标识符 |
| `style` | string | ❌ | `"default"` | min_length=1 | 样式变体名称 |
| `title` | string | ❌ | 无 | - | 自定义标题文本 |
| `subtitle` | string | ❌ | 无 | - | 自定义副标题文本 |
| `width` | integer | ❌ | `1179` | 640 ~ 2400 | 输出宽度 (px) |
| `height` | integer | ❌ | 自动 | 640 ~ 3200 | 输出高度 (px) |
| `luxury_theme` | string | ❌ | 无 | - | **奢华主题名/别名/random** |
| `luxury_theme_seed` | string | ❌ | 无 | - | 随机种子（random 主题可复现） |
| `luxury_theme_intensity` | float | ❌ | `1.0` | 0.0 ~ 2.0 | 主题强度 |

#### 响应头

```
Content-Type: image/png (或 image/gif)
Content-Disposition: inline; filename="radar_chart-neon_glow.png"
X-Legend-Type: radar_chart
X-Legend-Style: neon_glow
```

#### cURL 示例

```bash
# 基础渲染
curl "http://localhost:9001/render?legend_type=radar_chart&style=neon_glow&width=1200&height=1400" \
  --output radar.png

# 带奢华主题
curl "http://localhost:9001/render?legend_type=bar_chart&style=glass_3d&luxury_theme=gold&luxury_theme_intensity=1.5" \
  --output bar_gold.png

# 随机主题 + 可复现种子
curl "http://localhost:9001/render?legend_type=sankey_chart&style=neon_streams&luxury_theme=random&luxury_theme_seed=my_seed_42" \
  --output sankey_random.png
```

## 4. 奢华视觉主题系统 (Luxury Themes)

### 概述

奢华主题是**叠加在任意已渲染图表之上**的全局视觉滤镜系统。它通过调整亮度、对比度、饱和度、锐度、色调偏移、暗角效果和装饰边框，为输出图片添加专业级的电影质感。

### 工作流程

```
原始图表渲染 (PNG/GIF)
       ↓
  应用奢华主题滤镜
       ↓
  Brightness → Contrast → Saturation → Sharpness
       ↓
  Tone Tints (阴影/高光着色) → Vignette (暗角) → Border (装饰边框)
       ↓
  最终输出 (PNG/GIF)
```

### Random（随机主题）

```python
# 每次随机选择一个主题
GET /render?...&luxury_theme=random

# 配合种子实现可复现的随机选择
GET /render?...&luxury_theme=random&luxury_theme_seed=your_secret_key
```

> 相同的 `seed` 总是映射到相同的随机主题选择。

### 关闭奢华主题

以下值都会**禁用**奢华主题（返回原图）：
- `""` （空字符串）
- `"none"`
- `"off"`
- `"false"`
- `"disabled"`
- 不传该参数

### Intensity（强度）参数详解

| 强度值 | 效果 | 用途 |
|--------|------|------|
| `0.0` | 几乎无效果（仅 1% 偏移） | A/B 测试对照组 |
| `0.5` | 轻微效果 | subtlety 风格 |
| `1.0` | **默认标准效果** | 生产环境推荐 |
| `1.5` | 强化效果 | 展示/演示场景 |
| `2.0` | 最大强度 | 特效/海报级输出 |

### 高级：属性覆盖（Overrides）

可通过 `luxury_theme_overrides` 字典覆盖主题的任意单个属性：

```python
data = {
    "luxury_theme": "obsidian_gold",
    "luxury_theme_overrides": {
        "brightness": 1.15,
        "border_color": "#ff0000",
        "vignette_strength": 0.0
    }
}
```

### GIF 动图支持

奢华主题**完全支持 GIF 动图**：对每一帧独立应用滤镜后重新编码为 GIF。

```python
request = RenderRequest(
    legend_type="court_shot_animation",
    style="pulse",
    data={"luxury_theme": "ruby_noir", "frame_count": 15}
)
result = registry.render(request)
# result.media_type == "image/gif" ✅
```

## 5. Python SDK 使用

### 5.1 基础用法

```python
from neo_legend.models import RenderRequest
from neo_legend.registry import build_default_registry

registry = build_default_registry()

request = RenderRequest(legend_type="court_shot")
result = registry.render(request)

with open("chart.png", "wb") as f:
    f.write(result.content)

print(f"类型: {result.legend_type}")
print(f"样式: {result.style}")
print(f"格式: {result.media_type}")       # image/png 或 image/gif
print(f"扩展名: {result.file_extension}")   # png 或 gif
```

### 5.2 查询可用类型和样式

```python
from neo_legend.registry import build_default_registry

registry = build_default_registry()
types = registry.list_types()

for t in types:
    print(f"\n[{t.legend_type}] {t.display_name}")
    print(f"   默认样式: {t.default_style} | 格式: {t.media_type}")
    for s in t.styles:
        print(f"      - {s.name}: {s.description}")
```

### 5.3 批量生成所有图表

```python
import os
from neo_legend.models import RenderRequest
from neo_legend.registry import build_default_registry

registry = build_default_registry()
output_dir = "all_charts"
os.makedirs(output_dir, exist_ok=True)

for type_meta in registry.list_types():
    for style_info in type_meta.styles:
        request = RenderRequest(
            legend_type=type_meta.legend_type,
            style=style_info.name,
            width=1000,
            height=900
        )
        result = registry.render(request)
        filename = f"{type_meta.legend_type}__{style_info.name}.png"
        with open(os.path.join(output_dir, filename), "wb") as f:
            f.write(result.content)
        print(f"[OK] {filename}")

print(f"\n完成! 共生成图片于: {os.path.abspath(output_dir)}")
```

### 5.4 批量生成 + 奢华主题

```python
themes = ["obsidian_gold", "champagne_ivory", "sapphire_platinum", "emerald_onyx", "ruby_noir"]
```

```python
from __future__ import annotations
from neo_legend.base import BaseLegendSkill, StyleDefinition
from neo_legend._plotting import create_figure, add_canvas, save_png
from neo_legend.models import RenderRequest, RenderResult


class MyCustomChartSkill(BaseLegendSkill):
    legend_type = "my_custom_chart"
    display_name = "My Custom Chart"
    default_style = "awesome"
    default_size = (1200, 900)
    style_definitions = (
        StyleDefinition("awesome", "Awesome style."),
        StyleDefinition("cool", "Cool style."),
    )

    def render(self, request: RenderRequest) -> RenderResult:
        style = self.resolve_style(request.style)
        width, height = self.output_size(request)
        fig = create_figure(width, height, background_color="#ffffff")
        ax = add_canvas(fig)
        # TODO: 在这里绘制你的图表
        return self.result(save_png(fig), style)
```

```python
from neo_legend.my_chart import MyCustomChartSkill
```

## 9. 常见问题 FAQ

### Q1: 如何更改输出图片的质量/DPI？

当前系统固定使用 DPI=150。如需调整，修改 `_plotting.py` 中 `save_png()` 的 `dpi` 参数：

```python
fig.savefig(buffer, format=format, dpi=300, ...)
```

### Q2: 生成的图片太大怎么办？

1. **减小尺寸**: `width=800, height=600`
2. **简化数据**: 减少数据点数量
3. **选择轻量样式**: 如 `clean_quadrant` 比 `paper_quadrant` 更简洁
4. **降低奢华主题强度**: `luxury_theme_intensity=0.5`
5. **压缩输出**:

```python
from PIL import Image
img = Image.open(io.BytesIO(result.content))
img.save("compressed.png", optimize=True, quality=85)
```

### Q3: 中文字体显示为方框（□□）？

字体缺失问题。解决方案：

```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'DejaVu Sans']
```

或在系统中安装中文字体包。

### Q4: 奢华主题对性能有影响吗？

有轻微影响。奢华主题需要对每张图片进行像素级处理：

| 操作 | 耗时增量 |
|------|---------|
| 亮度/对比度/饱和度/锐度 | ~5-10ms |
| 色调偏移 (tone tints) | ~20-50ms (取决于分辨率) |
| 暗角 (vignette) | ~10-20ms |
| 边框 (border) | ~5ms |
| **总计 (1200x1400 PNG)** | **~40-80ms** |

对于 GIF 动图，每帧都会独立处理，耗时按帧数线性增长。

### Q5: 如何批量生成大量图表？

```bash
# 方法 1: 内置批量 API
curl -X POST http://localhost:9001/batch-generate -H "Content-Type: application/json" -d '{"output_dir":"./all_charts"}'

# 方法 2: Python 脚本
python generate_all_charts.py
```

### Q6: 支持导出为 SVG/PDF 格式吗？

当前仅支持 **PNG** 和 **GIF**。转换方案：

```python
from PIL import Image
img = Image.open(io.BytesIO(result.content))
img.convert("RGB").save("output.pdf", "PDF", resolution=150)
```

### Q8: 奢华主题可以组合使用吗？

不可以直接组合，但可以通过 `luxury_theme_overrides` 从一个主题基础上调优：

```python
data = {
    "luxury_theme": "obsidian_gold",       # 基础: 黑金风格
    "luxury_theme_overrides": {
        "border_color": "#c95770",         # 覆盖: 改用红宝石边框
        "highlight_tint="#ffd5dd"           # 覆盖: 改用玫瑰粉高光
    },
    "luxury_theme_intensity": 0.8          # 降低整体强度
}
```

```json
    "datasets": [...],

    "luxury_theme_intensity": 1.3
  }
}
```
